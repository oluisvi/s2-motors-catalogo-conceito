# S2 Motors — conceito de catálogo digital

Protótipo estático para apresentação, com três direções visuais alternáveis e catálogo de motos elétricas, patinetes e triciclos.

Fotos e dados dos produtos foram transcritos do catálogo compartilhado pela S2. Preços, estoque, especificações, garantia e endereço devem ser confirmados diretamente com a loja antes de qualquer uso comercial.

A seleção encaminha o interesse para o WhatsApp da loja. Este protótipo não processa pagamentos nem confirma disponibilidade.
